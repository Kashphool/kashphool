Kashphool editor handbook

How to update the website safely

Choose the content you recognise, update its fields, check the visual preview and save. This guide explains the full process without requiring any technical knowledge.

The editing workflow

Every update follows four steps

1

Choose a collection

Open the Content Manager and select a collection such as Events or Gallery & Media from the left-hand menu.

2

Open the content

Choose the named page or data set. Expand the grey section you want to change; collapsed sections keep long pages manageable.

3

Edit and preview

Change the text, dates or media fields. On supported pages, use the preview panel to check how the update will look.

4

Save your update

Review your changes, then use the save or publish control at the top of the editor. The public website updates after deployment.

What to edit where

Instructions for each website area

01 · Website Pages

Homepage

Choose Website Pages → Home Page, then expand Hero, About, Events, Gallery, Sponsors or Contact. Edit the fields inside the relevant panel and check the homepage preview.

  • Use Paragraphs for the About Us text.
  • Keep all three Statistics and Support cards.
  • Hidden fields are controlled by the website design.
Website Pages → Home Page

02 · Events

Upcoming event

Choose Events → Events and expand the event you want to update. Event dates, venue, map, registration and stall opening hours are all maintained here.

  • Date controls the public event range.
  • Stall hours are separate and can differ each day.
  • Enter times in 24-hour format, for example 15:00.
  • Next event ID must match the ID of the upcoming event.
Events → Events

03 · Sponsors

Sponsorship

Choose Sponsors → Sponsors to update current sponsor names, logos and links. Choose Sponsors → Sponsor Page for packages, prices, event information and enquiry wording.

  • Expand Sponsorship tiers to edit each package.
  • Keep all four tiers so the page layout remains balanced.
  • Past celebrations accepts one video and up to ten photos.
Sponsors → Sponsors / Sponsor Page

04 · Gallery & Media

Photos and coverage

Choose Gallery for public celebration photos, or Media Coverage for press videos, posters and the featured article. Select an existing asset or upload a new one.

  • Add clear alternative text describing every image.
  • The gallery supports between one and nine images.
  • Media Coverage keeps one featured video, one article and two supporting videos.
Gallery & Media → Gallery / Media Coverage

05 · Shared Content

Navigation, footer and contact details

Choose Shared Content → Shared Site Content to edit navigation labels, the footer, public email addresses and social links. These values appear in several places, so review the wording and links carefully before saving.

06 · Supporting pages

Constitution and error page

Under Website Pages, use Constitution Page to replace its PDF or wording. The Not Found Page controls the message shown when a visitor opens an unavailable website address.

Before you finish

Check, save and confirm

A short final check prevents most publishing mistakes. Uploaded media may appear in the preview before the update has been saved.

  1. Read the changed text once more and check names, dates and links.
  2. Use the visual preview where it is available.
  3. Save or publish the update from the top of the editor.
  4. After deployment, open View website and confirm the live page.
One source for event facts

Dates, venue and stall hours all come from Events. Update them there rather than repeating them on individual pages.

Layouts have safe limits

The gallery, media coverage and celebration photos show their allowed item counts in the editor. These limits protect the public layout.

Design assets stay protected

Header logos, backgrounds and decorative media are not managed here. Only replace files offered by a visible image or file field.

Not sure about an edit?

Leave the field unchanged and ask before saving. Avoid deleting or reordering fixed entries unless that is the intended website change.
